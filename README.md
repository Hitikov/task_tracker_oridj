# Arij — трекер задач для командной работы

## Описание проекта

**Arij** — кроссплатформенное приложение для управления проектами и задачами, предназначенное для командной работы. Приложение позволяет создавать проекты, распределять задачи между участниками, назначать исполнителей, устанавливать приоритеты и сроки, а также отслеживать ход выполнения работы.

В Arij предусмотрена иерархия задач «Эпик → Задача → Подзадача», а также представления для работы с задачами, включая Backlog и Kanban-доску.

## Цель проекта

Цель проекта — разработать удобный инструмент для организации командной работы, планирования задач и контроля прогресса выполнения проекта. Arij должен помочь участникам команды лучше координировать работу, распределять ответственность и получать общее представление о состоянии проекта.

## Зачем нужен трекер задач?

В современной разработке и управлении проектами ключевую роль играет организация работы. Трекер задач помогает:

- **Структурировать работу** — разбивать крупные цели на эпики, задачи и подзадачи;
- **Отслеживать прогресс** — видеть, на каком этапе находится каждая задача;
- **Управлять приоритетами** — расставлять важность задач и планировать бэклог;
- **Анализировать эффективность** — строить отчеты и графики для поиска аномалий;
- **Синхронизировать команду** — иметь единое пространство для работы всех участников.

Arij создается как упрощенный, но функциональный аналог Jira с акцентом на наглядность и удобство использования.

## Функциональные возможности

### Управление задачами
- Создание задач с автоматическим присвоением номера;
- Атрибуты: название, описание (текст/ссылки), тип, важность, дедлайн;
- Назначение исполнителя, изменение статуса;
- Иерархия: Эпик → Задача → Подзадача;
- Цветовая индикация для задач, принадлежащих к одному эпику;
- Настраиваемые типы задач, статусы и рабочие процессы.

### Способы визуализации информации

| Представление | Описание |
|---------------|----------|
| **Бэклог** | Список всех задач с возможностью приоритизации путем перетаскивания. Отображаются: статус, дедлайн, исполнитель, уровень важности. |
| **Канбан-доска** | Карточки задач распределены по колонкам-статусам. Поддерживается сортировка по эпикам. |
| **Календарь** | Задачи отображаются как события на основе их дедлайнов. |
| **Список (таблица)** | Таблица с колонками: название, статус, исполнитель, создатель, приоритет, требуемый результат, даты (создания, обновления, дедлайн, решения). Поддерживается сортировка и фильтрация. |
| **Timeline (временная шкала)** | Трехуровневое представление: проект → эпики, эпик → задачи, задача → статусы. Полоса времени разделена на цветные сегменты по времени нахождения задачи в каждом статусе. |
| **Reports (отчеты)** | Статистика за период: плитки с метриками, круговые диаграммы, гистограммы, линейные графики среднего времени выполнения. |
