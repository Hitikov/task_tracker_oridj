## Контракт

- API-контракт ([OpenAPI](../api/openapi.yaml)) без изменений.
- Уточнена клиентская валидация: имя 1–100 символов, пароль 8–128,
  key проекта `^[A-Z][A-Z0-9]{1,9}$`.
- Задача без явного статуса получает статус по умолчанию; дедлайн без времени
  трактуется как конец дня (`87f92b7`).
- Формат ошибок прежний: `{"error":{"code","message","details"}}`.

## Живые проверки

регистрация → вход → проект → участники → Epic/Task/Subtask → Backlog →
смена статуса → сохранение после перезапуска, плюс граничные случаи API
(невалидные поля, 403 для не-участника, 409 для дубликата key).
