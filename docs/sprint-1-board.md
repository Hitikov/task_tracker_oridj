# Доска первого спринта

Спринт 1: 16–28 ноября 2026. Цель — пользователь может зарегистрироваться, войти,
создать проект и убедиться, что данные сохраняются в PostgreSQL.

Источники: [ROADMAP](ROADMAP.md), [MVP](MVP.md),
[USER_STORY_FOR_REPORT](USER_STORY_FOR_REPORT.md).

## Колонки

| Колонка | Смысл | Правило перехода |
|---|---|---|
| Сделать | Задача запланирована, работа не начата | Карточка создаётся при планировании |
| В работе | Задача активно разрабатывается | Не более двух карточек у одного участника |
| На проверке | Код готов, ожидаются ревью и CI | Открыт PR, тесты добавлены |
| Готово | Задача принята | PR влит, CI зелёный, условие завершения выполнено |
